# Archived material

Files here are kept for the record but are not built into the package or
the pkgdown site (`archive/` is in `.Rbuildignore`).

- `advanced-methodologies.qmd`: vignette archived 2026-08-12, after the
  referee corrections in version 0.0.4.1008. It presented experimental
  features (`use_closed_testing`, `use_meinshausen`, `use_evalues`) with
  stronger claims ("controls FWER strongly", "state-of-the-art") than the
  package can support, and referenced a helper function
  (`prepare_block_data`) that does not exist. If these features mature
  and acquire proofs or simulation evidence, parts of this vignette may
  return.
